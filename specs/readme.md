# Specifications

Human-editable source documents for the vocabularies SAL implements. Nothing in this folder is generated; edit the files directly.

- `salmodule.ttl` is the SAL Module ontology in Turtle. It is the same document published at <https://w3id.org/sal/cgs-earth/sal-module-spec/salmodule#>, and the documentation site renders it verbatim on the "SAL Module TTL Spec" page, so a change here shows up there on the next docs build.
