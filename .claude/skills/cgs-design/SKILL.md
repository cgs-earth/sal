# CGS Brand Guidelines

Reference this palette and typography whenever producing CGS-branded output (CSS, HTML, slides, charts, etc.). Do not invent substitute colors or fonts — use the exact hex values and names below.

## How to apply

- **Primary palette** — use for main UI elements, headers, and key brand moments (Continental Green and Fluvial Blue are the strongest brand signals).
- **Secondary palette** — use for backgrounds, accents, and supporting text (Cream and Pavement Gray work well as neutral background/text pairs).
- **Gradients** — prioritize using the listed stop pairs, applied in the order given (first color → second color), for hero sections, backgrounds, or emphasis treatments — avoid blending arbitrary palette colors together unless there is a constraint that would require it.
- **Typography** — District Pro for headings/display text; Aptos for body copy. If District Pro is unavailable in the target environment, fall back to a clean sans-serif rather than substituting an unrelated brand font.
- **Assets** - CGS brand assets like logos can be found in the ./assets directory
- Check color contrast (e.g. dark text like Pavement Gray on light backgrounds like Cream or Cumulus Gray) before finalizing any text/background pairing for accessibility.
